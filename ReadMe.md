# Dino Wiki

## Description 

This is a colege competition I participated in and won 1st place.
The breif was to create a single web page using a single program file, this could have been in html (which I chose), java script, or any other.
You could make the page about anything of your choice but it had to be interactive and provide something useful or entertaining. 

I made a web page with a small wiki about some dinosaurs, since I made it some of the information and wikapidia links have become outdated. 

### How to run it

You must download the zip file provided, this holds the .html file and the images that are used for the project.
You then need to unzip the file and open the html file in your browser. 

If this does not work, open the html file in an IDE and run it. 
You may need to ensure you have a html and css development capable environment but this should not be requered. 


### The information I provided the judges

Dino Wiki (it's a small wiki)

This is a web page designed on a topic I have been really intrested in recently,
It has cards for each dino featured and these act as buttons to open a modal,
The modal has an overview / genral information on the dino and a link to there actual wikapidia.


Dinos on the site:
    Majungasaurus
    T.Rex
    Spinosaurus
    Velociraptor
    Triceratops
    Giganotosaurus
    Chicken

Technology used:
    I have imported Bootstrap 5.3.0 for the cards and models 
    The main part of the file is html but has scripts and sets for css.
    No java script has been used as I could accomplish my goal and idea without it.

Run information:
    To run this site you simply need to open the html file in your browser
    You will also need a working web browser, Firefox is recommended as it was the browser used for testing.
    It has been tested to work on Firefox, chrome and edge.
